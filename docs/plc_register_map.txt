------------------------------------------------------------------
SCALING / POSITION ENCODING
------------------------------------------------------------------
position_scale = 100

A holding register is unsigned, so a negative offset can't be written
directly. Every hole position is instead expressed relative to that
axis's servo home (see servo_home_positions above):

    raw = servo_home + round(mm x position_scale)      (clamped 0-4294967295)

Example: home 6000, hole 2.0 mm right of centre, scale 100 -> raw 6200.
2.0 mm the OTHER way -> raw 5800. No sign handling needed on the PLC side.

Raw value 0 on camera_positions is the "no hole found" sentinel — written
to both X and Y (both register words) with no servo-home read at all when
a camera finds nothing. This stays unambiguous only because every servo
home sits far from zero.

camera_positions and servo_home_positions are 32-bit: the raw value above
is split into two 16-bit register words, LOW WORD FIRST — the address
listed for an axis holds bits 0-15, the next address up holds bits 16-31
(low = raw & 0xFFFF, high = (raw >> 16) & 0xFFFF; the Mitsubishi D-register
double-word convention, matching this station's SLMP link). A raw value
that fits in 16 bits (the common case) simply leaves the high word at 0.
