                                 register 119 for completion.

                                 (500 ms) so the PLC can watchdog the PC.

                                 model_poll_interval_ms (1000 ms). The
                                 profile whose PLC Code matches this value

118   PC->PLC  result           Overall cycle result for ALL cameras:

119   PC->PLC  vision_complete  Set to 1 once every register above is

                                 PLC reads it, then resets this AND the

------------------------------------------------------------------
SCALING / POSITION ENCODING
------------------------------------------------------------------
position_scale = 100

A holding register is unsigned, so a negative offset can't be written
directly. Every hole position is instead expressed relative to that
axis's servo home (see servo_home_positions above):

    raw = servo_home + round(mm x position_scale)      (clamped 0-65535)

Example: home 6000, hole 2.0 mm right of centre, scale 100 -> raw 6200.
2.0 mm the OTHER way -> raw 5800. No sign handling needed on the PLC side.

Raw value 0 on camera_positions is the "no hole found" sentinel — written
to both X and Y with no servo-home read at all when a camera finds
nothing. This stays unambiguous only because every servo home sits far
from zero.
